# Sürüm notları

GitHub paketi Python Uçtan Uca V4 ve Excel Makro Rapor V4 kaynaklarını tek depoda bir araya getirir. Kaynak kod ve sentetik senaryolar ilgili sürümlerden alınmıştır. Ortak README ve başlangıç belgeleri günceldir. Alt klasörlerdeki V3 dosyaları önceki sürümün kayıtlarıdır.

V4'te önceki kapanış yorumlarını inceleme kuyruğuna alma, toplu düzenleme ve onay, kaynak kapanışın görünmesi ve mevcut dönem yorumlarının korunması eklendi.

Gider verisinden faturaya inen ayrıntı çıkarımı, otomatik neden metni üretimi ve yerel dil modeli deneyi bu paketin çalışma akışında yer almaz.
