# Bütçe Sapması — Makro Rapor V4

Windows masaüstü Excel üzerinde bağımsız VBA rapor uygulaması. Python veya PowerShell gerekmez. On modül içerir. Kurulum.vbs bilgisayarınızda Kontrol_Sablonu.xlsx'ten Butce_Kontrol_Makro_V4.xlsm oluşturur; hazır derlenmiş xlsm bu pakette yoktur.

[V4 kurulum ve kullanım](V4_YENILIKLER.md) ile başlayın. VBA proje erişimi kapalıysa [elle kurulum](KULLANIM.md) kullanılabilir. Şirket güvenlik ayarları otomatik değiştirilmez.

Çalışma Merkezi; kontrol listesi, hesap izi, eşleştirme değişiklikleri ve kalıcı kimlikler, adlandırılmış rapor seçimleri, kaynak alanı işaretleme, girdi arşivi, yeniden üretim ve güvenli durdurmayı sunar. Rapor hesabının MakroHesap.bas modülü önceki sürümle aynıdır.

Bu paket bağımsız **rapor** sürümüdür; eski yedi sayfalık Excel dashboard üreticisi ayrı dağıtımdır. Windows Excel bulunmayan geliştirme ortamında VBA derlemesi/çalıştırması yapılmamıştır. [Canlı kontrol](V4_CANLI_KONTROL.md) ve [test durumu](Dogrulama_Durumu.json) bu sınırı açıklar. [Yeni açık talepler](ORTAK_KARARLAR.md) otomatik açıklama ve gider detayı kurallarını içerir.

Yeni: **Önceki ayın yorumlarını getir** ve **Açıklamaları toplu düzenle**. [Kullanım ve 10 yorumluk örnek](V4_YORUM_KULLANIMI.md).
